# 🤖 RAG Assistant

RAG-ассистент для поиска информации и ответов на вопросы по базе знаний.

## 📌 О проекте

Проект создан для работы с документами и базой знаний. Ассистент получает вопрос пользователя, находит подходящую информацию и формирует ответ с помощью языковой модели.

## 🛠 Технологии

- Python
- ChatGPT / LLM
- RAG
- LangChain
- Pinecone
- Weaviate
- API
